# Baseline V1

2026-11-01 将现有导航冻结为 `baseline-v1`，对应源码提交
`6479e25f5825b5dbce9e6229a33ad5d564b0649a`。它是后续功能开发和回归比较的基线，标签不随新功能移动。

## 已有功能

- MID-360S 雷达惯性建图，地图保存、载入和定位。
- G12 APP 实时地图、缩放、选点、一次点击开始、取消、倍率和输入上限调整。
- 默认按位置到达；明确选择朝向时使用完整位置和朝向目标。
- 前进为主，支持前进与转向组合、原地转向；不以侧向平移代替转弯。
- E 左允许导航，E 中暂停，E 右或摇杆接管撤销导航；切回左档不会自行续走。
- 动态障碍绕行，无法绕行时导航输入归零并提示；保留传感器源时间和定位状态。
- 录包、轨迹、规划与控制回执，以及保留原失败的回放验证。

## 证据和范围

P2-1006 已有人工现场监护下的办公室往返和真人阻挡绕行记录。基线提交加入的最新终点和途中规划修复，完成了 229 项 Python 测试、实际 Nav2 插件的合成组件/平面响应模型测试及 GitHub CI 4/4；在1006核验了新 ARM 库、2293点实际路径预览及25次原生零输出。这个最新修订尚未完成新的真机运动复测。

仍有反向起步冻结地图回程重规划失败；12个较大角度长延迟转向模型中6个仍超调；某旧终点在该时刻快照中没有完整包络可行朝向。冻结快照可以包含真人障碍测试人员，不能等同于永久墙体。平面回放不构成双足平衡或真实环境全场景验收。

公开仓库提供导航源码和通用速度协议，不分发厂家私有全身驱动、策略、模型、地图、录包或凭据。具体机器安装配置单独备份，换机使用独立安装身份。
