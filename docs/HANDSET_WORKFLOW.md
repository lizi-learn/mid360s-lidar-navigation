# G12 导航执行界面

G12 使用原有 YMbot 操作台 APP 与配对网关。E 左档进入执行页，目的地和路线分开选择；切入左档本身不会发起运动。电脑管理页编辑点位、到达朝向、产品、话术和路线。

- 地图左侧，任务操作在右侧；开始与暂停在讲解详情前面。
- 选择保存的目的地，或点地图空白处产生临时目的地，再点一次“开始导航”。临时目标只存在于本次任务快照，不写入场地点位目录，也不要求到达后额外转向。
- 选择路线后点“开始巡游”。“行程与讲解”可展开查看。
- 中档暂停，回左档后点“继续导航”；右档或摇杆接管结束任务。“取消导航”和退出导航保持取消语义，不增加二次开始确认。
- 双指缩放、拖动平移与缩放按钮只影响地图显示。地图方向不会改变真实坐标。
- 顶部原生取消按钮独立于地图加载状态；主文档连接失败可重试，重连不会自动开始任务。
- 页面使用原有同源导航路径，不扩大 WebView 文件或跨域访问权限，不改变整机网关与走路驱动。

实际新任务仍通过现有导航规划、障碍与控制接口执行。UI、静态数据和模型验证不能替代现场行走；旧逆向返回及大延迟转身失败记录继续保留。
