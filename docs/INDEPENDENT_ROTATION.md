# 独立原地转向

`POST /api/rotate` 接收 `radians`，右转为负，左转为正；准备成功后仍由原来的 `/api/confirm` 单次开始流程执行。工具收到用户明确的转向指令时可以连续调用这两个接口，无需再向用户确认。

它使用 Nav2 Spin、实时局部地图、55cm 方形足迹与实际里程计转角，不调用全局路径规划，不生成前进或侧移指令。准备回执明确标记 `global_path_planned: false`，会话 `task_kind: rotation`、`path_points: 0`；准备成功不代表已经运动或整个转动范围已经验收。

E 右档、摇杆接管、取消、观测过期和障碍停车保留。转向受阻后停止该动作，不等待一个不存在的全局路径来恢复，也不重新执行完整相对转角。普通导航不会自动调用这项功能。

实际隔离 ROS/Nav2 测试覆盖右转90度且无平移、确认注入障碍后的零输出、手动接管后不自动恢复。本机405项测试通过。上述结果不等于实机转向或办公室往返通过。
