# 雷达中心导航坐标

`P2_NAV_REFERENCE=lidar_projection` 明确选择雷达中心的地面投影作为
Nav2 `base_link`，使用真实 LIO 位置及倒装安装方向对应的前向航向。
它不要求把这个点换算成骨盆中心，也不把颈部历史位置或驱动的占位零值
当成关节反馈。当前安装方向约定为倒装、出线朝后；其他安装需先修改方向配置。

运行方式示例：

```bash
P2_NAV_REFERENCE=lidar_projection P2_NAV_SUPPORT_HISTORY=true \
  bash navigation/console.sh --footprint-profile /path/to/installation-footprint.json
```

`body_kinematics` 继续使用已有的带时间戳头身变换。默认 `auto` 在没有头身
变换时仍为预演，不会自动开启新模式。显式选择的模式与头身变换参数冲突时
会报配置错误。

地形状态新增 `navigation_reference`、`navigation_reference_ready` 及原始
`reference_source_stamp_s`。雷达模式只在新鲜、有效位姿和速度计算成功后报告
导航坐标有效；`body_reference_ready`、`kinematic_feedback_ready` 仍为假。
原本名为 `calibration_ready` 的本地门状态/传输位为兼容现有协议保留，表示
所选导航坐标有效，不代表完成了机身外参或颈部标定。门和速度缓冲共同消费
同一模式，避免雷达位置已经输出，却在另一层仍被误当成缺机身关节。

# 非重复扫描的地面观测

可选 `P2_NAV_SUPPORT_HISTORY=true` 保存至多 250ms 的实际注册点云，按原始
ROS 消息头时间到期。点保持在世界坐标中，不随机器人移动或转向被搬运。
六块地面区域的大小、位置和每块至少两个实测点的要求保持不变。
当前地面拟合也保持不变；历史点按当前平面重新分类。新观察到低于平面的
返回会立即使相关判定失败并清空历史，避免旧地面掩盖新落差。
源时间重复、倒退、过期或无有效拟合时清空历史，不插值、不补点、不更新
缓存样本的源时间。碰撞监测仍使用当前扫描；此窗口不填充障碍扫描的未知方向。

一次固定头部、静止机身的实测对比中，同一批 120 帧的单帧六区域完整观测为
52 帧，250ms 实测点窗口为 87 帧。导航坐标有效 120 帧，机身/关节有效均为
0 帧，源消息头延迟最大约 82ms，无处理错误。尚有不完整区域；这不是完整
实机导航或动态步行的验收。设备未同步时，ROS 头来源为主机接收时间，
不能据此声称设备采样时钟已同步。

足迹由独立安装配置指定；选择雷达坐标不会自动修改其尺寸、障碍停车区域、
E 开关语义、摇杆接管、取消导航或速度限制。
