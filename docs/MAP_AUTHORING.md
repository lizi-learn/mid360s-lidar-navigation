# 同一张地图编排导览

打开 `/reception` 的「地图编排」，选择已经保存的场地地图。读取保存地图不需要启动导航、定位或电机。

1. 点「＋讲解点」或「＋途经点」，然后在地图上点击放置。拖动点位可以微调。
2. 点地图上的站点，在右侧填写名称、「在这个点说什么」、到点朝向、讲解后停留秒数，以及自动继续或等待访客点继续。精确坐标和关联产品放在折叠项中。
3. 在「路线顺序」选择或新建路线。打开「点选编入路线」，按顺序点击地图上的点位；可以上移、移除、开关介绍和设置有限循环。点各站的「编辑」直接返回点位设置，地图始终保留。
4. 点「禁行线」或「减速区」，依次在地图取顶点，点「完成绘制」。「通行限制」可以修改名称、移除标注和设置新标注的线宽、速度倍率。「保存更改」与点位路线一起保存；不会擦除雷达原图。
5. 选择路线后点「离线预演」。预演使用当前草稿和保存地图，显示路径、朝向、介绍字幕、停留和模拟继续；不会开始真实导航。修改草稿会使旧预演失效。

地图中的虚线连接表示站点顺序，并非可执行路径；预演实线才表示这次计算得到的路径。预演会指出无法通过的路段，不会移动点位、清除障碍或改写生产导航参数。保存历史内容仍可从运行记录恢复。

## 预演模型

这是保存地图的几何路径与任务流程预演，不是双足动力学或实时Nav2控制验证。为便于检查，模型速度为0.4m/s、转向为0.6rad/s，播放4倍速；这些值不会写入机器人速度设置。讲解为字幕示意，访客等待在3秒后模拟点击继续，实际任务仍等待真实「继续」操作。

预演搜索使用55cm方形的外接圆，包含占用格的范围；此预演可能比生产有向规划更保守。地图中未知区域保持未知。禁行线复用正式标注栅格，减速区复用速度倍率计算。预演不构成实际导航的验收门。

计算在独立低优先级进程进行，单次有时间和搜索量上限，同时最多一个计算。暂存文件随进程结束清除。前端只在打开地图或主动预演时传输栅格/轨迹，不将整张地图加入每秒状态查询。通行与点位数据仍按地图版本保存。

公开仓库仅包含通用实现与合成测试；实际楼层地图、点位、话术和视频保存在用户本机与对应机器。
