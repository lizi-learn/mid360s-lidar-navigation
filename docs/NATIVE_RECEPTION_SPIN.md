# 点位导航中的连续原地转向

操作仍是选点或路线后点一次开始。P2 导览会自动完成起步、到点转向、讲解和下一站；不增加人工确认。

- 原地转向复用 Nav2 Spin 的真实动作、完成及取消回执，最高转向输入保持 1.0。输入单位是所选 D 策略的手动等价输入，不承诺等于机身实测速率。
- 讲解点指定朝向后，以当前实测地图姿态检查；误差在 ±10° 内不再微调。没有指定朝向的点不额外转身。
- 正常前向弯行保持原控制。只有已规划路线开头确实需要大角度转身时才使用独立 Spin；随后从实际新姿态重规划原目标。
- 有指定朝向的路线预览仍用完整机身检查原目标与最终朝向。平移到点后，由独立 Spin 完成朝向，避免原跟踪控制器反复发短脉冲。
- 到点朝向完成前，不把中间的平移或转向动作成功当作参观完成，也不提前播放产品介绍。
- E 右档、摇杆接管和取消使当前任务失效；回到左档不会重放旧动作。E 中档暂停，按原流程主动继续。
- 真实障碍、传感数据中断和原生动作拒绝保留真实结果，不清障碍、不缩小机身，不伪造时间或完成回执。

原地转向不会改写地图或保存的点位。重启恢复位置时，关机前的位置仅能作为匹配初值；必须用当前实测扫描恢复当前定位。小协方差本身不能证明位置正确。定位修复不应变成人工验收文件或新增确认流程。

V2 baseline 是历史版本，原有标签与验证记录保留。新转向链路的仿真、接口测试与实机记录应分别报告。

临时障碍中断导览转向时，保留当前点位和剩余朝向，按原路线策略停车等待。监测状态连续恢复后，从当前实测姿态发起新的原生 Spin；原生动作再次检查真实代价图。阻挡期间不标记到达、不提前讲解，也不把中断的整段角度重复施加。等待受原有 max_wait、clear_hold 与 replan_interval 控制；超时保留失败记录。E 中/右档、摇杆和取消始终结束当前自动等待，返回左档不重放。
