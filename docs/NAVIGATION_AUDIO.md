# 机身平和语音提示

用户选择以机器人机身喇叭为主。导航只产生声音事件，独立的 `audio_worker.py` 读取本机状态并播放本地音频；它不加载 ROS、电机或步态客户端，只使用 `GET /api/status?summary=1`。声音失败不会改变运动允许、取消、接管或传感器判断。

| 事件 | 短句 |
| --- | --- |
| 收到实际导航执行回执 | 开始导航。 |
| 取消/停止 | 导航已停止。 |
| E中 | 导航已暂停。 |
| E右或摇杆接管 | 已切换为手动控制。 |
| 持续阻挡与重新规划 | 前方有障碍，正在调整路线。 |
| 较长绕行后恢复 | 路线已更新，继续导航。 |
| 已开始的任务失败 | 暂时无法继续，导航已停止。 |
| 开始前规划无路径 | 暂时没有找到可通行路线。 |
| 到达 | 已到达目的地。 |

短暂不足1.5秒的阻挡不播报；正常1Hz全局规划不触发语音。同类障碍15秒内不重复，短暂恢复不紧接着再说一遍“继续”。取消、失败和到达会淘汰陈旧提示，不堆积旧播报。服务启动、重连或导航进程重启时只读取当前状态，不补播旧“开始”。这些时间仅用于声音体验，不是导航阻断条件。

APP地图中的“机身声音”提供开关、0—100音量及试听。音量是本导航音频流的音量，不更改系统总音量。默认55，可自行调整；0或关闭时不播放。本机配置为 `audio-settings.json`，运行状态另存 `audio-feedback-state.json`。

```bash
python3 navigation/audio_worker.py \
  --url http://127.0.0.1:8930 \
  --settings /path/to/workflow/audio-settings.json \
  --voice-dir /path/to/your-voice-pack \
  --sink your-body-speaker-sink
```

语音包使用 `audio_feedback.PHRASES` 中的名称，例如 `started.wav`、`obstacle.wav`，为本地WAV。1006的自有短句通过现有语音合成配置一次生成，保留原速并统一响度；播放无需云端连接。私有语音包、云服务凭据和厂家音色/模型不放入公开仓库。公开版在缺少语音文件时生成原创、平滑淡入淡出的短音作为降级提示，不假装已播放中文语音。

`experiments/audio_feedback/check.py` 使用真实声音工作进程、合成状态服务器和模拟播放器，验证事件去重、静音、音量、失败隔离及零导航POST。真实声卡播放进程成功或回环录音有信号，只证明软件输出链路，不等同于现场听感已确认。
