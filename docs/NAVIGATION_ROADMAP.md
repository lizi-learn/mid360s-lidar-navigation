# Baseline V1 之后的功能建议

这是按当前双足平地产品需求给出的实施建议，不是新增的用户操作前置条件。
参考用户提供的《H款机器人用户使用手册(202609)》公开给用户的功能描述；该手册不披露内部导航算法，不能据此认定对方使用某一种规划或定位框架。仅借鉴产品功能和交互，独立实现，不复制其私有程序或素材。

| 建议次序 | 功能 | 具体交付 | 手册相关页 |
| --- | --- | --- | --- |
| 现在 | 平和声音、状态解释 | 开始/暂停/接管/到达/失败短句，阻挡与重规划合并，音量/静音/试听，回执日志 | 35、46、47 |
| 下一批 | 常用点位 | 将当前位置或地图选点保存成“出发点、办公室另一端”等名称，编辑/删除，一键前往或返回；每点独立选择是否指定朝向 | 13、42 |
| 下一批 | 路线与巡游 | A→B→C、往返、有限循环次数、停留时间、路线排序；可选到点音频。人工接管或取消终止任务，不自动恢复 | 24、37、38、46 |
| 下一批 | 规划与跟踪持续优化 | 处理已保存的反向起步/转身失败；区分真人绕障与方向波浪；减少途中停顿，保持前进与转向组合和现有缓冲 | 对应本项目已保存失败 |
| 再下一批 | 定位和地图工具 | 激光与地图叠加、可视化拖动/旋转校正；地图名称、版本、创建时间和切换；保留位姿图的续扫与局部更新 | 11、12、24—26 |
| 再下一批 | 地图标注 | 用户主动绘制禁行线、禁行区、减速区；默认空，不自动增加区域。对楼梯口等已知场地风险，标注语义与实际传感器能力分别显示 | 15—17 |
| 再下一批 | 目标被占用的体验 | 可选“到附近即可”：选择替代停靠点，结果明确标为“附近到达”。严格到点模式保持原容差，不把邻近点成功冒充原点精确到达 | 21、37 |
| 配套 | 诊断与回放 | 同步显示计划/实际轨迹、定位质量、x/z输入、障碍与语音事件；失败时保存原因，便于对比版本 | 20、23、24 |
| 配套 | 迁移与备份 | 导出地图、命名点位、路线、区域与版本；导入时显示地图和机器身份；公开代码与私有场地数据分别保存 | 26、27 |

建议先做“常用点位 + 一键往返 + 巡游列表”，能直接减少每次重复点地图的操作。定位/地图版本和用户标注是下一批产品工具。

双足适配继续围绕实测转向响应、行走摆动、雷达/机身IMU时序及颈部动态外参推进。只借鉴H的功能语义，其轮式底盘的速度参数和电机失能动作不套用到双足导航按钮。

跨楼层电梯、自动充电和多机调度放在后续场地集成阶段，涉及额外硬件和业务接口。当前MID-360S的能力、缺少深度相机的现实及平地使用范围应如实显示，不能仅通过软件文案声称具备全类跌落、透明物体等感知能力。
