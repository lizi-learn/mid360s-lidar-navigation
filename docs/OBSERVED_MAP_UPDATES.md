# 固定底图、低频学习与每日融合

默认保留固定底图。今天有人员或临时物品挡路，就使用原有实时避障等待或绕行；它们不写成永久地图障碍，也不把已经确认可通行的空间缩回去。

在「管理 → 地图工具与备份」中使用「低频学习 · 每日融合」。路过旧占用位置时，后台最多每秒取一个最新扫描，记录真正被多帧有限实测射线扫通的位置。至少8个不同源时刻；相邻支持允许低频采集间隔。当前定位/传感器状态无效、空扫描角度、被遮挡或仍有近邻实测端点的位置不增加空闲证据，未知格不补成自由格。

**积累证据不会发布或改写整张导航地图。** 新变化先保存在待融合区，默认每24小时最多自动融合一次，延后到导航任务空闲、无人操作摇杆时进行；不会为了融合取消正在走的任务。可点击「空闲时融合已观测变化」主动安排一次提前融合。融合后显示和规划使用同一份变化，禁行线与地图外边界仍按原语义执行。实时避障继续独立处理当下障碍。

原PGM不改写。`observed-map.json`分别保存已融合与待融合格，绑定原始格值、分辨率和原点的SHA256，保留各格首次/末次支持证据的原源时间和帧数。文件合并写入最多每分钟一次，导出/保存版本/正常退出前刷盘。地图版本和场地ZIP会携带两部分；待融合格在导入后仍是待融合，不提前变成可通行格。旧实时版本已经确认的变化可迁移保留。

取消勾选只暂停学习，固定地图继续使用。「恢复原底图并暂停更新」先保存版本，再清空已融合和待融合变化并暂停。正常导航不增加任何新的开始步骤。

AMCL仍使用原始底图。本功能面向已有场地中逐步发现的空闲空间，不代替大规模改装修后的局部续扫，也不宣称完整机身高度的3D净空。源时钟未同步时ROS头仍是主机接收时间；每日融合的批次时间与传感器原始时间分别记录。
