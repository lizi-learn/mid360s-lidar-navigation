# 临时障碍与地图更新

在「管理 → 地图工具与备份」中开启「自动更新旧障碍」。默认开启，不增加导航开始步骤。

人群、临时摆放的物品由原有实时避障层处理，不自动写成永久地图障碍。原底图里的占用格，如果后续雷达的有限实测射线多次穿过该位置，且回波在它后方至少25cm、附近没有障碍端点，才累计为空闲证据。默认至少8个不同源时刻、跨越2秒；局部定位/传感器状态无效时不积累。局部遮挡不会冒充扫通，未知区域不会被补成自由格。重新出现的实测端点会立即撤销相应旧格的空闲更新，原有实时避障仍独立工作。

更新同时进入页面栅格和 Nav2 全局静态输入，不是隐藏灰点。禁行线、地图外边界和原机身足迹保持原语义。AMCL仍使用原始底图；此功能处理已定位场地中的障碍变化，不代替大范围结构变化后的续扫/重建，也不宣称完整机身高度的3D净空。

原PGM不直接改写。变化保存为同目录的 `observed-map.json`，绑定原始格值、分辨率和原点的SHA256，逐格保留首次/末次支持证据的原源时间与帧数；不是靠页面刷新延长有效观测。换底图时不套用不匹配的旧证据。地图版本和场地ZIP把这份变化一起保存，换机导入不复制实时定位或机器人标定。

取消勾选只暂停学习，已保存的地图变化继续使用。「恢复原底图并暂停更新」先保存地图版本，再清空学习变化并暂停学习；可重新勾选继续。普通「查看版本/恢复」也包含这份变化。地图更新不取消或自动启动导航。

计算在只有一个最新扫描槽的后台线程进行，最多约4Hz，积压扫描被丢弃而不是排队延迟控制；旧占用变化合并为最多每秒一次整图发布，实时避障、禁行线和门状态更新不受此合并限制。地图文件合并写入不超过每5秒一次，导出/保存版本/正常退出前刷盘。页面可查看更新格数、开关与错误。当前传感器未同步时ROS头仍是主机接收时间，不能称为设备采样时钟精度。

自动学习只修正旧占用已被扫通的情况。新家具/新墙首先按实时障碍处理；需要将大规模新结构写入长期地图时，仍使用现有局部续扫与地图版本工具。
