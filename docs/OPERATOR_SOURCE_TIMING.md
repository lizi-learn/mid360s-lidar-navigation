# 原始遥控样本的2秒窗口

用户选择的原始遥控样本超时为2秒。接收消息解码、原始包快照、界面会话、D内原始包检查和原始操作者时间引用使用同一时长。读取、转发和等待不重写原始样本时间，也不借重复包续期。

该窗口只作用于原始遥控源。导航RPC与实时健康100毫秒、导航速度命令300毫秒、机身速度源500毫秒保持原实现。收到E右、E中或摇杆介入的新包时立即执行原接管/暂停行为，不等待2秒；超过2秒仍退出，恢复新数据不自行重启已退出的任务。

一次软件记录中的样本年龄达到160毫秒，仅说明导航侧当时未消费更新的原始样本，不能单独证明无线链路失联。区分无线接收、接收进程、DDS传递、原始包转发与D消费，需要对齐各层原始序号、生产时间和接收时间。接收端故障标志与无效档位没有被这个修改忽略。

针对性验证覆盖160毫秒与2秒边界、过期、重放、时间倒退、源身份变化、快照竞争、E右/中和摇杆即时接管，以及独立健康/命令的原超时。真实D二进制必须重新编译并核对运行身份；单独更新网页代码不能宣称端到端已生效。
