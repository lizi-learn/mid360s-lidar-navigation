# 纯转向与带朝向到点

这是 P2 平地候选的控制改进，尚无本次修订的双足实机运动复测。输入仍是策略量，不是米每秒：前向上限 0.75、转向上限 1.0、弯行前向约 0.6，保留操作者选择的倍率、y=0 和原输入斜坡。完整占地仍是总边长 55 cm 方块。

## 控制变化

正常前向弯行仍使用现有路径跟踪。起转和终点纯转向采用有界输入，停止输入后等待实测角速度回落，再根据实际转角、角速度峰值修正下一次输入时长。若有效反馈始终没有响应，则在原转向上限内提高下一次原始输入；仍先乘操作者倍率，再经过原输入斜坡，不绕过倍率。这样可区分“输入仍在穿越斜坡和死区”与“已经转动但尚未停稳”，减少在延迟下反复过冲。

仅有朝向要求的目标使用 `SettledHeadingGoalChecker`：沿用 0.15 m / 0.15 rad 位置与朝向容差，连续观测到线速度小于 0.03 m/s、角速度小于 0.03 rad/s、持续 2 秒后，任务才完成。这里的数值是该候选算法的参数，不是用户新增的人工确认或验收文件要求。目的是让“已到达”和介绍播报发生在停稳后。没有指定朝向的普通点位和连续途经点仍使用原来的 `PositionGoalChecker`。

`p2-flat-model` 配置开启 `FollowPath.settled_pivot_response`；通用配置默认关闭。终点转向仍受配置的角速度上限和原碰撞预测约束。取消、E 档位和摇杆接管行为不变。

## 可复现验证

构建扩展后，在隔离 ROS 域执行：

```bash
source /opt/ros/humble/setup.bash
source nav_controller_ws/install/setup.bash
export ROS_LOCALHOST_ONLY=1 ROS_DOMAIN_ID=209
cmake -S experiments/arrival -B /tmp/arrival-build
cmake --build /tmp/arrival-build -j2
python3 experiments/arrival/check_pivot_native.py \
  --binary /tmp/arrival-build/native_pivot \
  --output /tmp/new-pivot-evidence/report.json
```

实验使用实际 Nav2 控制器、目标检查器和进度检查器，合成的增益、死区、一阶响应及传输延迟模型。确认目标完成后立即停止继续发命令，随后让原传输队列自然排空，再检查残余角度；不会在目标完成后偷偷继续修正，也不会删除排队输入。包含原 12 组较大角度组合、48 组保留 0.5 操作倍率的组合、两组各 72 个扩展组合、实际代价图障碍和插件退出。每个输出目录保留参数、完整控制返回值、策略输入、模型施加值和失败。它不是厂商策略、双足动力学或真机验收。

另有实际 ROS action / 导览任务流程测试，覆盖带朝向目标完成、连续途经点、开门后改道、障碍绕行、中档暂停及人工接管。源码中保留旧的 `check_pivot.py`：它的“首次进入容差后永远停止修正”模型不能替代这些实际接口验证。早期直接调用插件、在检查器已返回成功后仍继续修正的中间实验，同样不等同于真实任务完成。

这组响应模型涵盖约 0.3–1.95 秒延迟，参数不代表已经辨识的真实步态。办公室冻结地图的窄处反向回程仍有独立失败；本次没有靠缩包络、清障碍、放宽容差或改时间戳处理它，也没有把该失败设为用户真机测试的新审批流程。

本次固定响应集合中：旧版原 12 组失败 6 组，新版 12 组通过；48 组半速和两组各 72 组扩展组合也通过。极端半速组合含目标完成后的排队响应复核最长 41 秒，配置的进度检查仍是 40 秒，并未放宽；实际检查器已在其原时限内完成。完整证据摘要见 [验证记录](SETTLED_PIVOT_VALIDATION_2026-11-02.json)。

CI 首次提交 `9c7b9e9` 的旧预瞄对比失败已保留：旧快速模型同时启用新转向等待，却用墙上时间计时。修正后该对比使用明确的仿真时钟，两个预瞄方案都关闭新转向响应以隔离变量；另由新的 204 组转向、8 组组合跟踪及实际任务流程检验完整新配置。没有降低原判定标准。

## 主路径的弯行输入

此前的0.6前向值主要出现在回退窗口和最小速度调节中，主RPP输出仍可能接近0.8。P2配置现在使用 `curved_forward_input: 0.6`，随转向输入平滑地把前向输出降到约0.6，保持转向输入，再对改变后的完整圆弧执行原碰撞预测。直行、零速、操作者倍率、原输入斜坡不变，也没有新增横移。实际插件日志已记录请求0.75、输出0.6、转向约0.487的同时输入。

中心障碍与左右各偏12cm的三个实际ROS流程均完成六项任务检查，障碍射线确实生效、整块包络侵入为零。它们仍是合成射线/平面运动模型；双足实机低速、晃动、介绍联动与减速区需要现场复测。旧75ca7fb的主CI绕障失败和同SHA标签CI通过同时保留，不以其中一次通过覆盖失败。

未并入“精确整块窗口”原型：三次流程通过但该分支触发次数为零；12个冻结快照只发现一处几何差异，并没有证明能解开所有原窗口均被拒绝的状态。当前改进不靠删除障碍、缩包络或降低原判定标准。冻结办公室反向回程仍有独立失败。
