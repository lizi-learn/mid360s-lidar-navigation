# S形策略输入候选

本次改动仍使用D策略的手动等效输入，不能将0.75解释成测得的0.75m/s。前向/转向最高输入、倍率、y=0、原源时间检查、E档位和摇杆接管均保留。

旧版用固定斜率增加前向输入，开始和结束爬坡时斜率会突变。候选仅在前向增加时用三段有限jerk轨迹：先渐增斜率、必要时保持、再渐减斜率。前向上升目标变化时保留当前输入及斜率，不每次从零重启；减速仍走原有下降响应。

| 输入 | 最大变化率 | 最大变化率的变化率 |
|---|---:|---:|
| 前向 | 0.30输入/秒 | 0.40输入/秒² |
| 转向（原有线性渐变） | 0.50输入/秒 | 保持原实现 |

恒定前向目标从0升到0.75的算术时间为3.25秒，旧线性限制为1.875秒。前向降低目标保留原0.8输入/秒的下降响应：起步优化不能给控制器的减速请求暗加制动距离。转向保留完整旧版0.5输入/秒线性渐变，包括方向变化和单轴零；0→1.0仍为2秒。调头脉冲上界保持原3秒，没有因改进前进起步而扩大。控制器明确撤回的单轴零立即清零，尤其是要求原地转时的前进零；它不是正常停车意图。

**尚未接通的部分：** 完整零向量目前不能区分正常到点归零与碰撞停车；现有生产合同将它视为立即清零，候选暂时保留该行为。正常停车到零的算术轨迹已覆盖测试，但还未被接为真实导航停车来源；不得据此宣称所有正常停车都已采用S曲线。需将正常制动意图与碰撞/取消分清并验证碰撞检查覆盖制动过程，而不是直接给所有零速命令增加拖尾。本项实现缺口不添加新的用户开始步骤或验收文件门。

无所有权、过期或无效反馈、取消及未分类零命令均立即清空轨迹。原始a560候选在完整回归出现急弯占地侵入、7/8航向跟踪失败，原件保留；仅恢复单轴零仍8/8失败，不能当作修好。79a4以较快转向曲线使航向8/8通过，但旧PivotBreakaway小角回归仍4/24失败（0.157rad超出原0.15rad判据）；该失败完整保留。f1be虽通过航向/位置与纯调头，却在高死区跟踪调头两项出现侵入：非零减速的拖尾增加了到点制动距离。仅改为3.5秒脉冲仍失败。最终将改动收敛到前向增加的S曲线，完整保留原减速、转向渐变与3秒调头上界；高死区4/4重新通过，没有放宽原判据。它不修复RL关节目标越界，不声称能凭输入曲线消除倒地；双足接触与策略仍须使用独立实机证据。

已做：472本机测试；200000步固定种子变目标及多种周期测试；240组冻结延迟/死区/增益/倍率转向集合；ARM纯算术/真实合同测试；实际隔离ROS2/Nav2连续导航、动态障碍、开门捷径、到点方向、讲解停留及人工接管流程。模型为合成平面运动，不是双足实机验收。候选尚未替换实际D或导航服务。
